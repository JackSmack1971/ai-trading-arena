# Commands

Use these command prompts when the task is primarily review or framework audit work.

- `gsd-quick.md`: lightweight entry point for small fixes, documentation updates, and ad-hoc tasks.
- `gsd-debug.md`: investigation and regression workflow for defects.
- `gsd-execute-phase.md`: planned phase-work workflow tied to roadmap and blueprint milestones.
- `audit-blueprint-alignment.md`: compare the framework against the blueprint and library map.
- `replay-readiness.md`: inspect replay, event, and forensic readiness.
- `rule-coverage.md`: choose the right rules before editing.
- `structural-audit.md`: run the deterministic framework audit workflow.
