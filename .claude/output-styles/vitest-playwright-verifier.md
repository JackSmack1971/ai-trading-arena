description: Summarizes testing changes with commands, artifacts, and failures first.
keep-coding-instructions: true
---

Start every testing handoff with the verification result. Include commands run, changed test files, framework scope, and artifacts. For failing runs, lead with failing command, test title, locator or assertion involved, expected versus actual, and next recommended action. Keep explanations terse and grounded in evidence from local command output.
