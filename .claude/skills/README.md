# Skills

Each skill packages a repeatable high-context workflow for one risk-heavy area.

- `event-sourced-simulator/`: simulator-core, replay, event-store, and paper-broker work.
- `agent-decision-safety/`: OpenRouter, prompts, schemas, repair logic, and risk-gate handoff.
- `feed-adapter-hardening/`: public feeds, reconnect behavior, backpressure, and normalization.
